# pdf_to_anki_edge

Convert a Russian frequency-list PDF into an Anki deck with TTS audio and
optional LLM-generated usage notes.

Each vocabulary entry becomes **two** Anki cards (RU→EN and EN→RU). Each card
carries three audio clips — the word itself, the example sentence at normal
speed, and the example sentence slowed down — and, if enabled, a short
plain-English usage note generated by a locally-running Ollama model.

Russian TTS is generated online via Microsoft Edge's neural voices by
default, with RHVoice and eSpeak NG available as offline alternatives.
Usage notes are **opt-in** (`--llm ollama`) and require Ollama to be
installed and running locally.

## What it produces

A single `.apkg` file you open in Anki (`File → Import`). For each entry in
the PDF you get:

**Card 1 — Russian → English**
- **Front:** the Russian word + word audio
- **Back:** pronunciation, English translation, the Russian example sentence
  (with the target word bolded), a 🐢 slow clip and a 🐇 normal clip of the
  sentence, the English translation of the sentence, an optional usage note,
  and the frequency rank.

**Card 2 — English → Russian**
- **Front:** the English translation
- **Back:** the Russian word, pronunciation, word audio, the same example
  block, an optional usage note, and the frequency rank.

Optional `--csv` writes a plain-text backup of everything the deck contains
(including the usage note if generated), which is useful for diffing between
runs or importing elsewhere.

## Requirements

- **Python 3.9+** (uses `tuple[str, str] | tuple[None, None]` type syntax and
  `list[dict]` generics)
- **Python packages:** `pdfplumber`, `genanki`, `edge-tts`
- **Optional system packages:**
  - `ffmpeg` — required if you use RHVoice or eSpeak NG (not needed for Edge)
  - `rhvoice` + `rhvoice-russian` — if you want the RHVoice backend
  - `espeak-ng` — if you want the eSpeak NG backend
- **Optional, for usage notes:**
  - [Ollama](https://ollama.com/download) installed and running locally,
    plus at least one pulled model (default assumed: `llama3.1:8b`)
- **Internet connection** — only for the default Edge TTS backend. Neither
  RHVoice, eSpeak NG, nor Ollama require internet once set up.

## Installation

### Linux (Debian/Ubuntu/Mint)

```bash
python3 -m pip install pdfplumber genanki edge-tts

# Optional offline TTS backends:
sudo apt install ffmpeg rhvoice rhvoice-russian    # for RHVoice
sudo apt install ffmpeg espeak-ng                  # for eSpeak NG

# Optional, for usage notes:
curl -fsSL https://ollama.com/install.sh | sh
ollama pull llama3.1:8b
